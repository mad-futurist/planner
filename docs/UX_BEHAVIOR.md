# UX behavior index

[SCREENS.md](SCREENS.md) owns navigation, interactions, loading/empty/error/offline states, permissions, drafts and picture provenance. [CONCEPT.md](CONCEPT.md) owns intended product behavior. [DATA_MODEL.md](DATA_MODEL.md#temporal-semantics) owns date/idea/completion rules.

Keep behavior in those owning documents rather than maintaining a duplicate screen specification. Verification belongs in [FEATURES.md](FEATURES.md) and [TESTING.md](TESTING.md).
